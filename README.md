# Workout Without Injuries

Workout Without Injuries is a local-first Android app that creates deterministic
workout plans from a person's training preferences, available equipment, experience,
and confirmed movement limitations. Users can review why exercises are excluded,
browse the exercise catalog, and adjust generated plans.

The app does not diagnose injuries or prescribe rehabilitation. Injury history is used
only to suggest movement limitations; the user decides which limitations apply.
